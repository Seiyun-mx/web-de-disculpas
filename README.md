
# Una disculpa especial

Página romántica e interactiva hecha con HTML, CSS, JavaScript y Node.js/Express.

## Requisitos

- Node.js 18 o superior
- npm

## Ejecutar localmente

1. Descomprime el proyecto.
2. Abre una terminal dentro de la carpeta.
3. Ejecuta `npm install`.
4. Ejecuta `npm start`.
5. Abre `http://localhost:3000`.

## Personalización

- Cambia los textos directamente en `public/index.html`.
- Colores, tipografías y animaciones: `public/styles.css`.
- Interacciones: `public/script.js`.
- El servidor Express está en `server.js`.

El backend solo sirve los archivos y ofrece `/api/health`.
No recopila ni guarda respuestas privadas.
